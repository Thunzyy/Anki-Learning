# English vocabulary decks

These four decks draw on the [New General Service List project](https://www.newgeneralservicelist.com/).

| File | List | Entries | Vocabulary |
| --- | --- | ---: | --- |
| `tsl.csv` | TSL 1.2 | 1,250 | Words specific to the TOEIC exam |
| `ngsl.csv` | NGSL 1.2 | 2,809 | Common English words, including function words |
| `ngsl_vocab.csv` | Filtered NGSL 1.2 | 2,622 | NGSL vocabulary excluding function words such as *the*, *a*, and *her* |
| `nawl.csv` | NAWL 1.2 | 963 | Advanced academic vocabulary |

The four decks contain 7,644 entries in total. The filtered NGSL overlaps with the full list.

## Card format

The front shows the English word and its IPA transcription. The back shows the French translation. Use **Definition** to show or hide the English definition.

## Import into Anki

1. Open Anki and choose **File → Import**.
2. Select the exported `.apkg` file.
3. To study in frequency order, set the deck's new-card order to sequential.

## Choosing a list

The New General Service List (NGSL) targets common English, with estimated coverage of about 92% of everyday English text. Together, the NGSL and TOEIC Service List (TSL) contain 4,059 entries, with estimated TOEIC vocabulary coverage of about 98.5%. The New Academic Word List (NAWL) covers academic vocabulary beyond the NGSL.

For TOEIC preparation, start with the TSL, use the filtered NGSL to consolidate common vocabulary, and add the NAWL if you need more advanced words.
