## Card Format

**Front:**
- Portuguese word

**Back:**
- French translation
- Category (verb, noun, adjective, grammar, expression, etc.)
- Frequency rank (#1 = most common word)

**2 card types:**
- Portuguese -> French
- French -> Portuguese

## Translation Notes

Translations were generated automatically from the frequency list and may need corrections in context.
Each word was translated with its grammatical category. Conjugated verb forms include the infinitive in parentheses (e.g. "fazendo" -> "faisant (fazer)").

## Import into Anki

1. Open Anki
2. File > Import
3. Select the `.apkg` exported from Learning
4. **Recommended setting**: Deck options > New cards > Order = Sequential

## Beginner Tip

Words are sorted by frequency. Start with a small selection and review the translations and examples before adding more words.
