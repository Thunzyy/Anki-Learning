## Card Format

**Front:**
- Spanish word

**Back:**
- French translation
- Category (verb, noun, adjective, grammar, expression, etc.)
- Frequency rank (#1 = most common word)

**2 card types:**
- Spanish -> French
- French -> Spanish

## Translation Notes

Translations were generated automatically and may need corrections in context.
Conjugated verb forms include the infinitive in parentheses (e.g. "haciendo" -> "faisant (hacer)").

## Import into Anki

1. Open Anki
2. File > Import
3. Select the `.apkg` exported from Learning
4. **Recommended setting**: Deck options > New cards > Order = Sequential

## Beginner Tip

Words are sorted by frequency. Learning the **first 500 words** covers the vast majority of everyday spoken Spanish.
